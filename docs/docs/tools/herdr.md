# herdr

コーディングエージェントのターミナルを載せる作業空間です。

## この環境での役割

- エージェントの入出力を、分割したペインで扱います。
- 専用の設定ファイルは配布しません。
- 版はmiseが管理します。上げ方は[導入後の更新](../update.md)です。

## 導入

- 導入手段はmiseです。
- 版の指定ファイルは`home/dot_config/mise/config.toml`です。キー名は`herdr`です。
- 確認コマンドは`herdr --version`です。

## 使い方

作業ディレクトリで起動します。

```bash
herdr
```

- デタッチしても、作業はサーバ側で続きます。既定では`Ctrl-b`のあと`q`でデタッチします。
- 再度`herdr`を実行すると、同じセッションへ戻ります。
- マシンを再起動したあとは、保存したレイアウトを復元します。
- 再起動で消えるのは、ペイン内の元プロセスです。対応するエージェントのセッションは、ツール側が再開できるものに限ります。
