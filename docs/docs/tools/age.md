# age

ファイルを公開鍵で暗号化し、秘密鍵で復号するツールです。

## この環境での役割

- 秘密情報の暗号化に、[SOPS](sops.md)と一緒に入れています。
- 鍵ファイルはこのリポジトリへ入れません。
- 鍵の置き場所と運用は未整備です。詳細は[今後の整備順序](../architecture.md#今後の整備順序)です。

## 導入

- 導入手段はmiseです。
- 版の指定ファイルは`home/dot_config/mise/config.toml`です。キー名は`age`です。
- 確認コマンドは`age --version`です。

## ツールの動き

- 暗号化に使うのは公開鍵です。
- 復号に使うのは秘密鍵です。
- 鍵ペアの作成コマンドは`age-keygen`です。
- どのパスへ鍵を置くかは、運用が決まるまでこの環境では定めていません。
