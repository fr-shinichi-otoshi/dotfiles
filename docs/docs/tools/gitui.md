# gitui

Gitのstatus、stage、commitを画面で行うツールです。

## この環境での役割

- リポジトリ直下で起動するGit操作画面です。
- 専用の設定ファイルは配布しません。

## 導入

- 導入手段はmiseです。
- 版の指定ファイルは`home/dot_config/mise/config.toml`です。キー名は`aqua:gitui-org/gitui`です。
- 確認コマンドは`gitui --version`です。

## 使い方

```bash
gitui
```

Gitリポジトリの中で実行します。入力待ちになる画面です。
